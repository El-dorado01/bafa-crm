Project Summary
You're building a specialized CRM for managing BAFA-funded consulting projects (BAFA is a German federal funding program). This is a domain-specific compliance platform, not a generic CRM.

Key Requirements:
1. Three User Roles with Strict Permissions:

Client - Can only upload/sign documents, view their own projects
Consultant - Can report status, issue invoices, but cannot change official case statuses
Funding Advisor - Only role that can change case statuses, approve documents, and submit to BAFA (single source of truth)
2. Case Management:

23 predefined case statuses following BAFA funding workflow
Manual status changes (no automation in MVP)
Status flow: Lead → Eligibility Review → Document Collection → BAFA Submission → Consultation → Invoicing → Reporting → Approval → Payout → Closed
3. Document Management:

13 document types from 3 sources (Client, Consultant, Funding Advisor)
8 document states (Requested → Uploaded → Reviewed → Correction Required → Corrected → Approved → Submitted to BAFA → Archived)
All documents follow same state workflow for compliance
4. Features:

Secure login with role-based access
Project-based document upload/management
Simple project communication between participants
No automation, calendars, or advanced analytics in MVP

Authentication: Set up Supabase email/password auth with role-based access
Core UI: Build project dashboard, project detail views, document management, and communication interface
Permissions: Implement strict role-based access controls per the specification

Based on the typical workflow for a BAFA-funded consulting project, here is a recap of what a Client (SME) should be allowed to do in the CRM:

1. Project Tracking
View Project Status: See exactly where their funding application stands (e.g., "Consultant Assigned", "Drafting Report", "Submitted to BAFA", "Approved").
View Timeline: See upcoming deadlines and milestones.
2. Document Management (Critical for BAFA)
Upload Required Documents: Clients must upload specific legal documents (e.g., Gewerbeanmeldung, Handelsregisterauszug, Steuerbescheide, De-minimis-Erklärung).
View/Download Reports: Access the final consulting report and BAFA notices (Zuwendungsbescheid).
3. Communication
Chat with Consultant/Advisor: Direct line to their assigned expert.
Approve Steps: Digitally sign or approve specific stages (e.g., approving the final consulting contract or reports).
4. Company Profile
Manage Business Details: Update address, legal form, founding date, and industry (all critical for BAFA eligibility).
